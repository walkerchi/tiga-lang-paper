\begin{abstract}
Message passing provides a common programming abstraction for dense, sparse,
and dynamically generated numerical computation beyond graph neural networks.
Achieving high performance requires preserving interaction structure while
adapting execution to hardware, memory capacity, and communication costs.
We present Tiga, a cross-platform, multi-backend just-in-time compiler that
separates graph message-passing semantics from traversal, kernel generation,
storage placement, and distributed execution. Its multi-level intermediate
representations retain relations and reducer algebra for fusion and
differentiation, while backend-specific lowering targets CPUs through LLVM
and NVIDIA GPUs through Triton. A Python interface interoperates with ordinary
PyTorch tensors, alongside a Torch-independent native runtime.
Memory-constrained systems, including laptops, motivate a hierarchical storage
design that stages graph partitions across disk, host memory, and device memory
with a bounded GPU working set. This enables billion-edge graph computation
on a memory-limited single GPU without requiring the complete graph and its
fields to reside in device memory. Distributed execution partitions ownership
and exchanges halo values across devices and hosts under the same
message-passing model. Evaluation against Torch sparse and PyTorch Geometric
demonstrates runtime and device-memory improvements for generated relations,
validates billion-edge forward execution beyond device-memory capacity, and
characterizes communication and load-balance costs on heterogeneous devices.
Together, these mechanisms establish a common compiler foundation for
high-performance graph computation across backends, memory tiers, and
distributed deployments.
\end{abstract}
