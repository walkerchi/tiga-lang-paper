# Official ICLR 2027 style files

The `.sty` and `.bst` files in this directory are unmodified copies from the
[official ICLR 2027 archive](https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip),
downloaded on 2026-09-21. The archive is linked by the
[author guidelines](https://iclr.cc/Conferences/2027/AuthorGuidelines).
Their original notices are retained. Standard TeX Live packages provide
`natbib` and `fancyhdr`; duplicate copies from the archive are not bundled.

SHA-256 checksums are recorded in `checksums.sha256`. The source archive has
its own checksum in that file for provenance; it is not required for building.

The manuscript wrapper changes only the review-status wording to identify an
unsubmitted workshop draft. It does not change template margins, fonts or
spacing. An eventual workshop's own template and instructions take precedence;
the main-conference page limit is not a confirmed workshop requirement.
